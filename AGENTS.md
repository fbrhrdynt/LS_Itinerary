# Project instructions

For UI work, read `DESIGN.md` first and apply the anti-slop rules from https://github.com/miqdadbadjuber/anti-slop as a filter.

- Build around the actual task of the screen, not a default dashboard template.
- Never invent metrics, activity, testimonials, or trust claims.
- Every navigation item and control must work.
- Keep empty, error, and blocked states honest and actionable.
- Prefer real data hierarchy over decorative cards.
- Run `npm run check` before shipping backend or UI changes.
